# hao-backprop-test

Test project for backprop integration. Built with Python 3 and Flask.

## Prerequisites

- Python 3.12+
- pip

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python3 app.py
```

## Behavior

The server binds to `127.0.0.1:3000` and returns `Hello, World!` with a `200 OK` status and `Content-Type: text/plain` for all HTTP requests, regardless of method or path.
